# 个人学术主页

这是一个简洁、无需构建工具的 GitHub Pages 学术主页。修改 `site.config.js` 即可更新姓名、单位、邮箱、Google Scholar 链接、研究方向、论文与教育经历。

## 发布

1. 在 GitHub 新建公开仓库，仓库名必须是 `wenlin-hub.github.io`。
2. 将本文件夹中的所有文件上传至仓库根目录。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)`，保存。
5. 网站地址为 `https://wenlin-hub.github.io/`。

发布后，在 Google Scholar 个人资料中点击编辑，将网站地址填入 **Homepage**。
